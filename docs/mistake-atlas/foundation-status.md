# 个人学习系统实施状态

日期：2026-08-03

## 产品边界

系统底层使用通用学科模型，已预留数学、408、英语和政治。当前仅完整启用数学，其他学科只展示“框架预留”，不提供具体教材、分类和业务数据。

## 已实现

- 单用户主人账号、Argon2id 密码、7 天 HttpOnly/Secure/SameSite 会话；
- 未授权设备阻止页面、登录失败限流、退出当前/全部设备；
- 首次登录修改初始密码；
- 可修改网站名称、副标题、描述、品牌色、网站图标、阻止页文案和首页问候语；
- PostgreSQL + Prisma 通用学科数据模型和版本化迁移；
- 数学教材、章节、知识点、错误类型；
- 数学错题新增、编辑、软删除、恢复、Markdown/LaTeX 和私有图片；
- 重做历史、连续独立正确计数、做错清零、三次正确自动掌握、掌握后错误自动回退；
- 今日复习、已做对、已掌握、反复错误；
- 仪表盘、周报、未来 7 天复习预报；
- Markdown 批量导入预览、缺失分类自动建立、重复检测、整批回滚与完整 JSON 导出；
- OpenAI 兼容 AI Provider 接口和发送上下文预览；
- Nginx HTTPS、安全响应头、非 root systemd 服务和独立私有数据目录。

## 尚需外部资料才能启用

- AI 分析需要在服务器环境变量中提供 `AI_BASE_URL`、`AI_API_KEY` 和 `AI_MODEL`；
- 具体数学教材和完整章节树需要由使用者按自己的资料录入；
- 408、英语和政治只保留通用学科框架，当前未启用具体内容。

## 关键安全规则

- 除阻止页、健康检查和网站图标外，所有页面与 API 都要求有效主人会话；
- 图片存储在 Web 根目录外，并通过鉴权接口读取；
- 未提供公开注册、找回密码、公共题库或分享功能；
- 导出的 JSON 不包含密码、会话、API Key 或图标二进制数据。
